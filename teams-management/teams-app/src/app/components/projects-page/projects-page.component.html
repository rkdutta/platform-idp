👁️ Read-only access — you can view the projects and applications you've been granted, but not change them. Ask a project owner for access.

🛠️ Project manager — you can create new projects. Like an owner, you can order and delete namespaces and manage source repos for projects you own, from the Users page, but you can't delete projects you don't own. Only admins delete arbitrary projects.
